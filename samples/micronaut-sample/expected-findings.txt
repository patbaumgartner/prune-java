#   unused     prune-java must report exactly this set of (type, symbol) pairs.

#

#              With test references excluded it is reported with exactly this

#              positive that deletes live code is the worst failure mode this
#              project has. The type column names the guard that keeps the
#              symbol when explanations are requested, or ANY when the symbol is
#              referenced by an identifier and never reaches a guard.
#

# so a @Controller, @Factory, or @Singleton class is never named in Java. The
# annotationProcessor and runtimeOnly configurations are not analyzed at all.
